NEP Travel - Web Design Project

Developing a travel site is part of Web Design project work, it is created using vs code platform. NEP Travel features attractions from Nepal withing its beautiful landing page.

Overview of the Project

NEP Travel is a simple travel website designed with following features:

- Responsive menu
- Hero section
- Popular places
- Travel packages
- Events
- New interface made with Flexbox and CSS Grid technology 
- Easy scrolling menu
